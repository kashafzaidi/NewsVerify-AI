 NewsVerify AI

NewsVerify AI is a Machine Learning based web application that predicts whether a news article is Fake or Real.

I created this project to understand how text data can be processed using Machine Learning and how a trained model can be connected to a web application using FastAPI.

Features

* Predicts Fake or Real News
* TF-IDF for text processing
* Logistic Regression for prediction
* FastAPI backend
* Interactive web interface

Technologies Used

* Python
* Pandas
* Scikit-learn
* FastAPI
* HTML
* CSS
* JavaScript

Dataset

The model is trained on a dataset containing 44,898 news articles, including both Fake and Real news.

Model Accuracy

The model achieved 98.99% accuracy on the test data.

Note

NewsVerify AI is a Machine Learning based prediction system. It does not check live internet sources or independently verify facts. The prediction is based on patterns learned from the training dataset.
